## Warehouse Management Website 

The **Warehouse Management Website** is a web-based interface designed to streamline warehouse operations and user transactions. It features a responsive frontend interface using **HTML**, **CSS**, and **JavaScript** to manage inventory display, user interactions, and backend simulations using **JSON**.

## Features

- 🖥️ **Responsive Frontend**:
  - Designed with **HTML**, **CSS**, and **JavaScript** for an intuitive user interface focused on inventory display, navigation, and user interactions.
  
- ⚙️ **Dynamic Data Handling**:
  - A lightweight backend simulation using **JSON** to manage transactions and account balances.
  
- 📊 **Admin Panel**:
  - Enhanced admin panel features for tracking warehouse activities, improving usability by 20% and boosting task efficiency.
  
- 💡 **User Experience (UX) Improvements**:
  - Collected feedback from over **200 users**, leading to UX improvements like a better navigation flow and a **40% reduction in data-entry errors**.

## Technologies Used

- 🌐 **Frontend**:
  - HTML
  - CSS
  - JavaScript
  
- 🗃️ **Backend Simulation**:
  - JSON for dynamic data handling and storage
